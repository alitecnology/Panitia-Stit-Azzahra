Tambah, ubah, atau hapus pertanyaan. Tiga isian bawaan (nama, jenjang, jurusan) tidak bisa dihapus.

Sistem dan Keamanan Server

Penjelasan jujur tentang cara kerja server ini, perlindungan yang aktif, dan batasnya.

Penilaian: cukup kuat untuk website sekolah, tetapi tidak ada sistem yang "sangat aman" atau "tidak bisa dibobol". Titik terlemah ada di akun Google pemilik, jadi aktifkan verifikasi 2 langkah.

Sistem yang dipakai

  • Website pendaftaran dan website admin berupa file HTML statis di hosting.
  • Server memakai Google Apps Script. Semua data tersimpan di Google Sheets milik pemilik script (sheet pendaftar, config, log).
  • Nomor WhatsApp disimpan di Script Properties, bukan di kode.
  • Admin masuk lewat Google Sign-In. Server memeriksa token ke Google dan hanya menerima satu akun admin yang terdaftar di server.

Alat dan lapisan keamanan yang aktif

Batas dan risiko yang masih ada

  • Anti-DDoS tidak bisa dibuat lewat kode. Pasang Cloudflare (gratis) di depan domain, dan ingat Apps Script punya kuota harian Google.
  • Akun pendaftar di website pendaftaran dibuat di browser masing-masing, belum diverifikasi server. Siapa pun bisa mengirim formulir, dibatasi hanya oleh pembatas laju. Periksa data yang mencurigakan sebelum diterima.
  • Data pribadi (NIK, alamat, data orang tua) tersimpan apa adanya di Google Sheets. Siapa pun yang menguasai akun Google pemilik bisa melihatnya.
  • CSP masih mengizinkan skrip inline karena Tailwind versi CDN membutuhkannya.
  • Tidak ada fitur unggah berkas, jadi risiko malware lewat file tidak ada. Berkas dikirim lewat WhatsApp.

Saran

  • Aktifkan verifikasi 2 langkah di akun Google pemilik script, dan jangan bagikan spreadsheet datanya.
  • Ekspor CSV secara berkala sebagai cadangan.
  • Periksa sheet "log" sesekali untuk melihat percobaan akses yang ditolak.

Dokumen hukum

Syarat dan Ketentuan serta Kebijakan Privasi tampil di bagian bawah website pendaftaran dan di halaman login. Ubah link-nya di tab Rahasia.

Perhatian: kedua dokumen TermsFeed yang sekarang dipakai dibuat untuk "Website game", berbahasa Inggris, melarang pengguna di bawah 18 tahun (Syarat) dan di bawah 16 tahun (Privasi), serta menyebut layanan yang tidak dipakai di sini (Mouseflow, FreshDesk, Google Places, SMS pemasaran). Itu tidak cocok untuk PPDB yang datanya mencakup anak di bawah umur dan NIK. Sebaiknya buat ulang dokumennya dengan data yang sesuai.
